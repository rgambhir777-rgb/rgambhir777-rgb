## Selected Work

### Scoring Multi-Turn LLM Virtual Agents

Testing agentic, LLM-driven virtual agents across chat, voice, email and SMS before they reach customers. A virtual agent can sound fluent while losing context, giving wrong answers or inventing facts mid-conversation, so each test conversation is built from real customer journeys and every turn is scored for context awareness, accuracy and hallucination.

The result is quality evidence the business can use to decide when the agents are ready for real callers.

---

### AI-Assisted Playwright Framework

An enterprise Playwright framework built faster with Cursor, GitHub Copilot and MCP, without giving up review. AI generated first drafts of page objects, locators and fixtures from source, DOM and requirements; every draft went through human review and an automated test run.

The result is a scalable Page Object Model architecture with shared standards for locators, fixtures, synchronization and parallel runs.

---

### Playwright API and UI Test Suite

End-to-end workflows that combine API and UI checks in one Playwright suite, using custom fixtures, API interception and backend validation.

150+ API tests automated, 70% less manual regression effort, and more defects caught before production.

---

### High-Volume Load Testing

Distributed JMeter testing for peak events, where failure means people can't enroll, log time or buy. Found maximum stable capacity at 3,000 concurrent users and 1,200 enrollments an hour, and tested other systems at up to 8,000 and 10,000 users.

---

### Multimodal Agentic RAG Assistant (personal project)

An AI agent that answers questions from PDFs, scanned forms, screenshots and call transcripts, and cites the exact page or clip it used. An eval set scores retrieval recall, groundedness, citation accuracy and hallucination for each content type, and runs in CI.

---

### PUM Upgrade to PeopleTools 8.63 with AI Adoption

Upgrading PeopleSoft to PeopleTools 8.63 and getting testers and users ready for its new AI features. Natural Language Search, Magic Button AI actions and MCP-connected agents were tested against real data and security roles, alongside PTF regression, role-based training and Oracle Guided Learning walkthroughs.
